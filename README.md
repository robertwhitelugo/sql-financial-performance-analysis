# Financial Performance Analysis with SQL

## 📌 Project Overview

This project analyzes a company's financial performance using SQL.

The objective was to transform raw transactional data into meaningful business metrics such as revenue, expenses, profit margin, and Return on Investment (ROI), supporting business decision-making through data analysis.

---

## 💼 Business Problem

A company operating across multiple international markets needed to evaluate its financial performance and understand how revenue, operational expenses, and marketing investments affected profitability.

Analyzing revenue alone was insufficient to determine which markets performed best. A country with higher sales could also have higher costs, resulting in a lower profit margin or a less favorable return on investment.

This project addressed four business questions:

- Which countries generated the highest revenue?
- How did operational expenses and marketing investments affect profitability?
- Which markets achieved the strongest profit margins?
- How did Return on Investment (ROI) differ across countries?

To answer these questions, SQL was used to calculate and compare financial performance indicators across markets.

The goal was to provide a clearer view of business performance and support data-driven decisions about cost management, profitability, and investment priorities.

## 📊 SQL Analysis & Methodology

### 1. Financial Data Analysis

The project focused on analyzing financial performance across the United States, Canada, and Australia.

The analysis considered five key financial indicators:

- **Revenue:** Total income generated by each market.
- **Expenses:** Costs associated with business operations.
- **Gross Profit:** Revenue minus the costs included in the financial calculation.
- **Profit Margin:** Profit expressed as a percentage of revenue.
- **Return on Investment (ROI):** A measure of financial returns relative to the investment considered.

### 2. SQL Techniques

The analysis used SQL and PostgreSQL, incorporating the following techniques:

| SQL Technique | Analytical Purpose |
|---|---|
| `JOIN` | Combine information from related tables |
| `CTE (WITH)` | Organize calculations into reusable query steps |
| `SUM()` | Aggregate financial amounts |
| `GROUP BY` | Calculate metrics for each country |
| `CASE WHEN` | Apply conditional logic to financial calculations |
| Calculated expressions | Derive profitability indicators and ratios |

### 3. Financial Performance Comparison

Financial indicators were compared across markets to investigate:

- Differences in revenue generation.
- The relationship between expenses and profitability.
- Variations in profit margin.
- Differences in ROI between countries.

### 4. Business Interpretation

The analysis went beyond comparing sales totals.

By examining revenue alongside expenses, profit margin, and ROI, the project provided a broader assessment of financial performance.

These comparisons helped identify markets with different financial strengths and areas requiring further investigation.


---

## 📈 Results

The analysis identified the most profitable markets by comparing revenue, operational costs, marketing investment, profit margin, and ROI.

Key findings include:

- United States generated the highest revenue and ROI.
- Canada achieved the highest profit margin.
- Australia maintained strong profitability with moderate ROI.
- The project demonstrates how SQL can transform transactional data into actionable business insights for strategic decision-making.
