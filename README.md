# SQL Financial Performance Analysis

## 📌 Project Overview

This project analyzes a company's financial performance using SQL.

The objective was to transform raw transactional data into meaningful business metrics such as revenue, expenses, profit margin, and Return on Investment (ROI), supporting business decision-making through data analysis.

---

## 🎯 Objectives

- Analyze financial performance.
- Calculate business KPIs.
- Measure profitability.
- Calculate ROI.
- Practice advanced SQL querying.

---

## 🛠 Technologies

- SQL
- PostgreSQL
- CTEs
- JOINs
- Aggregate Functions
- CASE WHEN
- GROUP BY

---

## 📊 Key Analyses

- Revenue analysis
- Expense analysis
- Profit Margin
- ROI calculation
- Financial KPI reporting

---

## 📈 Results

The project demonstrates how SQL can transform transactional data into business insights by calculating financial KPIs that support strategic decision-making.
